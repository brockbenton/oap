<interfaces>
Rehearsal API contract (verified from source):
- POST /api/v1/sessions (authMiddleware + adminMiddleware = on-chain ADMIN_ROLE of req.user.walletAddress). Body zod: { sessionId: numeric string, date: ISO datetime string, name: 1-200 chars, semester: 1-100 chars }. 201 { data: { sessionId, onchainStatus: 'CONFIRMED', txHash, ... } } only after the on-chain createSession receipt (up to 120s). 409 CONFLICT, 500 CHAIN_ERROR.
- GET /api/v1/sessions/:sessionId/qr (admin) -> 200 { data: { qr: string } }; 409 if closed or not CONFIRMED.
- POST /api/v1/check-in body { qrPayload: string, memberSignature: 0x-hex, signedAt: int ms } -> 202 { data: { checkInId, jobId, sessionId, memberAddress, status: 'PENDING' } }. Errors 400 STALE_SIGNATURE / INVALID_QR / INVALID_SIGNATURE / ADDRESS_MISMATCH, 409 ALREADY_CHECKED_IN / SESSION_NOT_READY / SESSION_CLOSED.
- Signed message (check-in.ts step 3): `I am checking into session ${qr.sessionId} as ${privyWalletAddress} at ${signedAt}` where privyWalletAddress is LOWERCASE.
- Auth seam (middleware/auth.ts): getPrivy() lazily builds `new PrivyClient(PRIVY_APP_ID, PRIVY_APP_SECRET)` and calls `getUser({ idToken })`, reading `user.id` and `user.wallet?.address`.
- The worker runs only when startMintWorker() (backend/src/jobs/mint.job.ts, returns Worker) is called. Queue: `mintQueue` from backend/src/lib/queue.ts. On-chain read: `tokenBalanceOnChain(address, sessionIdOnchain): Promise<bigint>` from backend/src/services/onchain.service.ts. Prisma default export from backend/src/lib/prisma.ts; model `checkIn` with fields id, mintStatus ('PENDING'|'CONFIRMED'|'FAILED'), txHash.
- Env read at import time: lib/contract.ts (RELAY_PRIVATE_KEY, ADMIN_SIGNER_PRIVATE_KEY, CHAIN_ID, ALCHEMY_API_KEY), services/qr.service.ts (QR_TTL_MS), services/relay.service.ts (CONTRACT_ADDRESS). So rehearse.ts must load dotenv and validate env BEFORE any dynamic import of src.
- Root /.env format (D-07): 6 lines, alternating a label line (`backend`, `frontend`, `contract`) and a value line. Research shape probe: each value is 62 chars, no 0x prefix, not hex-only, no spaces, so none is a private key.
