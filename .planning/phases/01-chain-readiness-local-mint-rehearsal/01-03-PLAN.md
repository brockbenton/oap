Create backend/scripts/lib/chain.ts (pure helpers, no side effects at import):
- `ROLES = { DEFAULT_ADMIN_ROLE: zeroHash, ADMIN_ROLE, RELAY_ROLE }` (name -> bytes32).
- `makePublicClient()`: baseSepolia chain, http transport to the Alchemy URL when ALCHEMY_API_KEY is non-placeholder, else https://sepolia.base.org. Never print the URL.
- `resolveContractAddress(flag?: string)`: `--address` flag, else CONTRACT_ADDRESS env, else addresses.json["AttendanceRegistry"]["base-sepolia"]; validated with isAddress, returned checksummed.
- `accountsFromEnv()`: for each of RELAY_PRIVATE_KEY, ADMIN_SIGNER_PRIVATE_KEY, DEFAULT_ADMIN_PRIVATE_KEY, CANDIDATE_DEPLOYER_PRIVATE_KEY (backend/.env) and PRIVATE_KEY (smart-contract/.env, read via readEnvFile) that is a valid /^0x[0-9a-fA-F]{64}$/ value, return { source: envVarName, address } using privateKeyToAccount. The key itself is never returned to callers that print.
- `findDeployBlock(client, address)`: binary search over getCode({ address, blockNumber }) from 0 to latest (first block with code); flag `--from-block N` overrides when the RPC lacks archive state.
- `scanRoleHolders(client, address, deployBlock, chunk)`: getLogs RoleGranted/RoleRevoked for the single deploy block first (yields deployer and original relay), then deployBlock+1..latest in chunks (default 2000, halve on a range-limit error down to 10), apply events in (blockNumber, logIndex) order, and return current holders per role plus the deploy-tx deployer (the `sender` of the constructor grants).
- `probeRoles(client, contract, addresses)`: hasRole for all three roles per address via readContract with ATTENDANCE_ABI.
- `decide(probes)`: returns { decision: 'KEEP', via: sourceEnvVar } when any env-derived address holds DEFAULT_ADMIN_ROLE, else { decision: 'REDEPLOY' } (D-03 rule, verbatim).
- `getBalances(client, addresses)` returning wei.

Create backend/scripts/chain-inspect.ts (import 'dotenv/config' first; `main().catch` exits 1 with a message passed through a redaction of ALCHEMY_API_KEY). Default mode prints: contract address and whether code exists; deploy block and deploy tx deployer; a table `ROLE | HOLDER ADDRESS | LABEL` where LABEL is the env source (relay, admin-signer, default-admin, candidate-deployer) or `unknown`; a table of hasRole results for every env-derived address; balances in ETH for env-derived addresses; then exactly one line `DECISION: KEEP (via <ENV_VAR>)` or `DECISION: REDEPLOY (no available key holds DEFAULT_ADMIN_ROLE)`. Flag `--check` (CHAIN-02 gate, used by plans 04 and 06): exit 1 unless RELAY_PRIVATE_KEY, ADMIN_SIGNER_PRIVATE_KEY and DEFAULT_ADMIN_PRIVATE_KEY are all valid and pairwise distinct addresses, relay holds RELAY_ROLE, admin-signer holds ADMIN_ROLE, default-admin holds DEFAULT_ADMIN_ROLE, and balances are at least relay 0.005 ETH (RELAY_MIN_BALANCE_ETH, default 0.005), admin-signer 0.002 ETH, default-admin 0.001 ETH; print `CHECK PASS` or one `CHECK FAIL: <reason>` line per failure. Flag `--addresses` prints only labelled addresses and balances (used by the faucet checkpoint). Flags `--address`, `--from-block`, `--chunk` as above.

Create backend/scripts/gen-wallets.ts (D-06, Claude's discretion: viem generatePrivateKey instead of `cast wallet new`, so keys never hit the terminal): for RELAY_PRIVATE_KEY, ADMIN_SIGNER_PRIVATE_KEY, DEFAULT_ADMIN_PRIVATE_KEY in backend/.env: keep an existing valid key; if missing or placeholder, generatePrivateKey() and setEnvVar. Refuse (exit 1, nothing written) if any two resulting keys are equal. Print `<ENV_VAR> -> <address> (generated|kept)` only. Must not import backend/src/lib/contract.ts.

Run (Node 22): `cd backend && fnm exec --using=22 -- npx tsx scripts/chain-inspect.ts` against the current contract, before any wallet exists, and keep the output for the checkpoint and the SUMMARY.
