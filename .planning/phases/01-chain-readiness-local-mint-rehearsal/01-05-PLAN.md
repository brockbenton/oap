<objective>
Guard the walking skeleton against silent drift: a check script (and CI job) that fails when the contract address or ABI disagrees between the forge artifact, addresses.json, backend and frontend; and pin Node 22 across the repo and CI.

Purpose: the contract is not upgradeable, so every future redeploy must update the address and ABI in all layers. This check turns a silent production break into a red CI build. Node 22 pinning makes the rehearsal runtime identical to CI/Railway/Vercel.
Output: abi-sync comparator + tests, check-sync CLI, CI sync-check job, Node 22 pins, rewritten sync-abi.md.
</objective>
